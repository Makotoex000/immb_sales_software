Uma solução moderna e eficiente para gestão de vendas, controle de estoque e monitoramento de desempenho comercial.

## 📋 Sobre o Projeto

O **IMMB Sales Software** foi desenvolvido para simplificar o fluxo de vendas, permitindo que gestores e vendedores tenham controle total sobre as transações, clientes e produtos em uma interface intuitiva.

### Principais Funcionalidades:
* **Gestão de Inventário:** Controle rigoroso de entrada e saída de produtos.
* **Registro de Vendas:** Histórico detalhado de transações em tempo real.
* **Cadastro de Clientes:** Base de dados organizada para CRM básico.
* **Relatórios Automáticos:** Dashboards de faturamento e itens mais vendidos.

## 🛠️ Tecnologias Utilizadas

Este projeto utiliza as seguintes tecnologias (ajuste conforme seu código):

* **Linguagem:** Node.js
* **Banco de Dados:** SQLServer
* **Interface:** Angular

## 🚀 Como Executar

Para rodar o projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/Makotoex000/immb_sales_software.git](https://github.com/Makotoex000/immb_sales_software.git)
    ```

2.  **Acesse a pasta do projeto:**
    ```bash
    cd immb_sales_software
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Inicie a aplicação:**
    ```bash
    npm start
    ```
